# 下午茶时光 - 女性社交平台

## 项目简介

"下午茶时光"是一个专为女性打造的高品质社交平台，致力于通过精选活动、深度社交和内容分享，帮助女性用户发现美好生活，连接同频好友。

## 技术栈

- HTML5
- CSS3 / Tailwind CSS
- JavaScript (原生)
- Font Awesome 图标库

## 功能模块

### 1. 首页横幅
- 优雅的背景图与文字设计
- 花瓣飘落动画效果
- 响应式设计，适配各种屏幕

### 2. 活动广场
- 精选活动卡片展示
- 点击卡片查看详情弹窗
- 悬浮动画交互效果

### 3. 产品核心价值
- 发现美：精选城市优质活动
- 连接人：智能匹配同频好友
- 愉悦心：高品质体验舒缓压力

### 4. 核心功能详解
- 活动详情：结构化信息展示
- 聊天社交：群聊/私聊/安全机制

### 5. 社区分享功能
- 美好瞬间：记录精彩时刻
- 生活灵感：分享美学创意
- 一键分享：多平台分享支持

### 6. 专属个人主页
- 个人档案、参加历史
- 收藏与关注、会员中心

## 运行方式

直接在浏览器中打开 `index.html` 即可预览网站。
